### Setting Up the Job Applications Dashboard on Windows

Since you already have Node.js installed, here's a detailed guide to set up the job applications dashboard project on your Windows system.

## Step 1: Create a New Next.js Project

1. Open Command Prompt or PowerShell by searching for it in the Start menu.
2. Navigate to the directory where you want to create your project:

```plaintext
cd C:\path\to\your\projects\folder
```


3. Create a new Next.js project with Tailwind CSS:

```plaintext
npx create-next-app@latest job-applications-dashboard --typescript --tailwind --eslint
```


4. When prompted, select the following options:

1. Would you like to use TypeScript? → Yes
2. Would you like to use ESLint? → Yes
3. Would you like to use Tailwind CSS? → Yes
4. Would you like to use `src/` directory? → No
5. Would you like to use App Router? → Yes
6. Would you like to customize the default import alias? → No (or Yes and use @/* if you prefer)



5. Navigate to your new project directory:

```plaintext
cd job-applications-dashboard
```




## Step 2: Install Required Dependencies

Install the necessary dependencies for the project:

```plaintext
npm install lucide-react recharts @radix-ui/react-select @radix-ui/react-tabs @radix-ui/react-popover @radix-ui/react-dropdown-menu @radix-ui/react-slot @radix-ui/react-dialog class-variance-authority clsx tailwind-merge
```

## Step 3: Set Up shadcn/ui Components

1. Initialize shadcn/ui in your project:

```plaintext
npx shadcn@latest init
```


2. When prompted, select the following options:

1. Would you like to use TypeScript? → Yes
2. Which style would you like to use? → Default
3. Which color would you like to use as base color? → Slate
4. Where is your global CSS file? → app/globals.css
5. Do you want to use CSS variables? → Yes
6. Where is your tailwind.config.js located? → tailwind.config.ts
7. Configure the import alias for components? → @/components
8. Configure the import alias for utils? → @/lib/utils
9. Are you using React Server Components? → Yes



3. Install the required shadcn/ui components:

```plaintext
npx shadcn@latest add button card table tabs select badge input popover dropdown-menu calendar
```


4. Create a chart component for shadcn/ui:

```plaintext
mkdir -p components/ui/chart
```


5. Create the chart component files:

Create a file at `components/ui/chart/index.tsx` with the following content:

```plaintext
npx shadcn@latest add chart
```

If the above command doesn't work (as chart might not be an official shadcn component), you'll need to manually create the chart components as shown in the project code.


## Step 4: Create Project Structure

Create the necessary folders for the project:

```plaintext
mkdir -p components/charts components/tables components/lists lib
```

## Step 5: Add the Code Files

Now, copy all the code files from the dashboard project into your project structure:

1. Create `lib/types.ts` and add the ApplicationData interface
2. Create `lib/data-generator.ts` and add the data generation logic
3. Create all the chart components in the `components/charts` folder
4. Create the table components in the `components/tables` folder
5. Create the lists components in the `components/lists` folder
6. Create the main `components/analytics-dashboard.tsx` file
7. Update `app/page.tsx` to use the AnalyticsDashboard component


You can copy the code for each file from the project I provided earlier.

## Step 6: Run the Application

1. Start the development server:

```plaintext
npm run dev
```


2. Open your browser and navigate to:

```plaintext
http://localhost:3000
```


You should now see the job applications dashboard running locally on your machine.

## Troubleshooting Common Issues

1. **Module not found errors**: Make sure all dependencies are installed correctly. You might need to restart the development server after installing new packages.
2. **TypeScript errors**: If you see TypeScript errors, make sure you've copied all the type definitions correctly.
3. **Chart rendering issues**: If charts aren't rendering properly, check that you've set up the chart components correctly and that the data structure matches what the charts expect.
4. **CSS issues**: If the styling looks off, make sure your globals.css file includes all the necessary Tailwind directives.


## Additional Notes

- The dashboard generates random application data each time it loads. If you want to use real data, you'll need to modify the `generateApplicationData` function in `lib/data-generator.ts`.
- The CSV export functionality works by generating a CSV file from the current application data and triggering a download.
- All charts and visualizations are interactive and responsive, so they should work well on different screen sizes.
